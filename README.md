# 無人機小組・時間協調系統

9 位組員各自在自己的手機／電腦打開同一個網址，選自己的名字後就能填寫空堂時間、看全員空堂總表、模擬三組（機身／主翼／尾翼）分組、追蹤任務進度。所有資料存在雲端的 Google 試算表，大約每 8 秒自動更新一次畫面，任何人重新整理也一定看到最新狀態——不是各自獨立的單機版。

## 架構

- **前端**：`無人機小組時間協調系統.html` 單一網頁，手機／電腦瀏覽器都能開，不需要安裝任何東西。
- **後端＋資料庫**：**Google Apps Script + Google 試算表**
  - 後端是一支部署成「網頁應用程式」的 Apps Script（`Code.gs`），它綁定一份 Google 試算表，試算表就是資料庫，存放課表、分組、任務與進度紀錄。
  - 進度紀錄的現場照片會先在瀏覽器端壓縮，再由 Apps Script 存進你的 Google 雲端硬碟（一個叫「無人機小組課表系統照片」的資料夾），試算表裡只存照片網址。
  - 完全**免費、不需要信用卡**，只需要一個 Google 帳號（用學校信箱或個人 Gmail 都可以）。
- **身份辨識**：打開網站選自己是哪一位組員即可，**不需要密碼、不需要註冊帳號**。裝置會記住身份，換人使用時點「切換身份」即可重選。

> 因為拿掉了密碼，只要知道網址的人都可以編輯資料——這是你們要求的「不需要複雜帳號系統」的取捨。網址不要公開貼出去，只在小組內部分享即可。

### 跟即時性有關的小差異

Google Apps Script 的網頁應用程式沒有像正式資料庫那樣的「即時推播」，所以前端改成**每 8 秒自動向後端要一次最新資料**（分頁切到背景會暫停，省用量）。實際體驗是：自己按下的操作立刻生效，別人的操作大約 8 秒內會自動出現在你畫面上；就算不想等，手動重新整理一定看到最新狀態，符合原本的需求。

## 部署步驟（由一位組員完成即可，大約 10 分鐘）

1. 前往 [Google 試算表](https://sheets.google.com)，用你的 Google 帳號建立一份「空白試算表」，取個名字（例如「無人機小組課表資料庫」）。
2. 上方選單「**擴充功能 → Apps Script**」，會開啟一個新分頁的程式碼編輯器，裡面預設有個空的 `Code.gs`。
3. 把整個編輯器裡的內容刪掉，貼上這個資料夾裡 [`Code.gs`](Code.gs) 的完整內容，按 Ctrl+S（或上方的存檔圖示）存檔，專案取個名字（例如「drone-schedule-backend」）。
4. 上方函式下拉選單選 `init`，按「執行」▶️。第一次執行會跳出「需要授權」的視窗：
   - 選你的 Google 帳號 → 可能會看到「Google 尚未驗證這個應用程式」的警告，這是正常的（因為是你自己寫的程式，不是別人上架的公開軟體）→ 點「進階」→「前往 drone-schedule-backend（不安全）」→ 允許存取試算表與雲端硬碟。
   - 執行完成後可以在「執行項目」紀錄看到成功訊息，回到試算表也會看到多了 `Members`、`Groups`、`Tasks` 三個分頁。
5. 左側選單點「部署 → 新增部署作業」：
   - 類型選「**網頁應用程式**」（點齒輪圖示選）。
   - 執行身份：「**我**」。
   - 具有存取權的使用者：「**所有人**」（這樣組員才不用登入 Google 帳號就能用）。
   - 按「部署」，會再跳一次授權確認，同意即可。
6. 部署完成後會顯示一組「網頁應用程式」網址（`https://script.google.com/macros/s/.../exec`），複製起來。
7. 打開專案裡的 [`apps-script-config.js`](apps-script-config.js)，把 `YOUR_APPS_SCRIPT_WEB_APP_URL` 換成剛剛複製的網址，存檔。

完成以上步驟後，`無人機小組時間協調系統.html` 就已經連上你的 Google 試算表了。

**之後如果修改了 `Code.gs`（例如未來想擴充功能）**：改完存檔後，一定要「部署 → 管理部署作業 → 編輯（鉛筆圖示）→ 版本選「新版本」→ 部署」，否則線上網址不會套用新程式碼——這是 Apps Script 常見的坑，單純存檔並不會更新已部署的網頁應用程式。

## 讓 9 位組員都能打開

跟後端網址不同，**前端網頁本身也需要放到一個網址上**大家才能打開（用 `file://` 直接雙擊開啟，部分瀏覽器可能會擋掉跨網域讀取，不建議）。推薦：

### GitHub Pages（免費、不需要額外帳號以外的東西）
把這個資料夾（`無人機小組時間協調系統.html`、`apps-script-config.js`）push 到一個 GitHub repository，到 repo 設定的 Pages 分頁啟用 GitHub Pages，指到根目錄，幾分鐘後就會有一個 `https://帳號.github.io/repo名稱/無人機小組時間協調系統.html` 的網址可以分享。

或者你有其他慣用的免費靜態網頁空間（Netlify、Vercel 等）也都可以，把這兩個檔案放上去即可。

把「網址」傳給另外 8 位組員，大家各自打開網址、選自己的名字即可開始使用，之後每次打開都會記得身份。

## 資料怎麼存的（給想維護程式的人看）

| 試算表分頁 | 內容 |
|---|---|
| `Members` | 固定 9 列，各自的姓名、每週 7×13 節的空堂表（存成 JSON 字串） |
| `Groups` | 固定 1 列，三組（機身／主翼／尾翼）分組結果與是否鎖定 |
| `Tasks` | 每項任務一列：組別、負責人、日期時段、進度百分比、現場紀錄（含照片網址） |

前端用 `fetch` 跟 `Code.gs` 溝通：`GET` 拿完整狀態，`POST`（`Content-Type: text/plain`，避免瀏覽器送出 CORS 預檢請求卡住）帶一個 `{action, payload}` 送出各種寫入動作。

畫面上「① 匯入課表」的檔案匯入邏輯（Excel／.ics／PDF／截圖辨識）程式碼還在，但目前版面沒有對應的上傳欄位，實際可用的填寫方式是點「填寫」直接手動點格子——如果之後想開放檔案匯入，把對應的 `<input type="file" data-a="file">` 加回 `viewImport()` 即可沿用既有的解析函式。

## 疑難排解

- 打開網頁看到「尚未連接後端資料庫」：`apps-script-config.js` 還沒填、或填錯了，回頭檢查步驟 6–7。
- 操作後過一陣子跳「連線發生問題」或畫面沒反應：多半是部署權限不是「所有人」，回到「管理部署作業」確認存取權限；或是改了 `Code.gs` 後忘記部署新版本（見上面的提醒）。
- 出現「找不到任務」：代表兩人幾乎同時操作同一項任務時發生了小小的競速狀況，重新整理一次即可，Apps Script 內建了鎖定機制避免資料寫壞，只是偶爾要多按一次重新整理。
- 想把所有人資料清空重來：打開網站點右上角「清除全部資料」（會影響所有人，請先確認大家都同意）。
- 覺得每 8 秒自動更新太慢／太耗流量：可以打開 `無人機小組時間協調系統.html`，搜尋 `}, 8000);` 把數字改大或改小（單位是毫秒）。
